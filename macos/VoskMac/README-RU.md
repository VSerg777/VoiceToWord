# Vosk Word Listener для Mac

Нативное приложение для macOS с офлайн-распознаванием речи Vosk. Использует ту
же русскую модель `vosk-model-small-ru-0.22`, что и приложение Windows. Аудио
обрабатывается локально.

## Сборка

На Mac установите Xcode Command Line Tools, затем выполните из этой папки:

```sh
./build.sh
```

Результат: `macos/VoskWordListener.app`. Динамическая библиотека Vosk включена;
модель скачивается отдельно.

## Первый запуск

1. После распаковки ZIP нажмите правой кнопкой мыши на приложение, выберите
   «Открыть», затем ещё раз подтвердите запуск в предупреждении macOS. Приложение
   подписано локальной ad-hoc подписью, а не Developer ID.
2. Скачайте и распакуйте русскую модель Vosk. Нужна папка с `am/final.mdl`.
3. Откройте приложение и нажмите «Выбрать модель…», затем «Загрузить».
4. Оставьте «Системный микрофон Mac (по умолчанию)» или выберите другое
   устройство, затем нажмите «Диктовать». Если список не показывает ваш
   микрофон, выберите системный вариант и проверьте вход в System Settings →
   Sound → Input.
5. При запросе разрешите доступ к микрофону. Перед началом диктовки приложение
   проверит разрешение Accessibility. Нажмите «Открыть настройки», включите
   Vosk Word Listener в System Settings → Privacy & Security → Accessibility,
   затем закройте и снова откройте приложение. Если в списке уже есть старая
   запись приложения, удалите её и добавьте приложение заново.
6. В списке «Куда вставлять текст» выберите нужное приложение либо оставьте
   «Активное поле». Для выбранного приложения поставьте курсор в его текстовое
   поле; при начале диктовки приложение автоматически выйдет на передний план.
   Завершённые фразы будут вводиться туда; полный текст остаётся в окне Vosk.
   Нажмите «Обновить приложения», если приложение не видно.

`Control` + `Option` + `D` начинает или останавливает диктовку, когда разрешён
Accessibility. Приложение сохраняет выбранную папку модели для следующего запуска.

Распознавание использует ту же модель и голосовые команды, что версия Windows:
пунктуация, новые строки и абзацы, «буквально», удаление, отмена и замена
единственного совпадения.

macOS использует Audio Unit для микрофона и Accessibility API для ввода в другие
приложения. Поддержка отдельных программ зависит от того, разрешает ли их поле
ввода прямую установку текста или синтетические клавиатурные события.
